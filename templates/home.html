About EduTune

EduTune is an advanced machine learning application designed to predict student engagement and performance in educational settings. The system uses a stacked ensemble approach combining multiple regression algorithms to provide accurate predictions.

Key Features:
  • Multiple regression algorithms (KNN, SVR, Decision Tree, Hybrid Stacking)
  • Comprehensive exploratory data analysis
  • Real-time performance metrics comparison
  • Single and batch prediction capabilities
  • Automated model training and persistence
Prediction Targets:
Engagement Score

Predicts student engagement levels based on behavioral and physiological metrics.

Performance Score

Predicts academic performance based on skill development and learning metrics.
